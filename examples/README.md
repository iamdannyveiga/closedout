# Examples

This directory is for real transcripts, one file per loop, taken from work that
actually ran under the doctrine.

The shape of an example is fixed by the four artifacts. A single file per loop
holds the brief that was sent, the worker output it produced, the two inspector
verdicts as they were written, and the verification command with its raw output.
Nothing is rewritten for publication: the point of an example is that it is the
run that happened, including the FAIL round and the fix that followed it. A
transcript that shows only the clean pass is marketing, and this file is not
marketing.

The first transcripts will come out of the build of this package itself, where
the brief is in the repository history, the ledger rows are in the database of
the machine that ran it, and the artifacts under `out/` are named for the loop.
Two of them are worth writing down first because they show the doctrine working
rather than merely being described: a loop that the ledger refused to close, and
a bake-off that moved a lane to a different model with the three numbers that
decided it in the receipt line.
